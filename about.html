Explicación

Este documento funciona como el registro técnico del proyecto "Hotline Miami Web". A continuación, se detalla la estructura semántica utilizada en la construcción de la interfaz principal, justificando el uso de cada etiqueta HTML5 para garantizar accesibilidad, correcta indexación y organización del código, junto con una breve explicación del proceso de creación de la página.

Estructura Principal

  • <header>: Se utiliza en la parte superior para contener el título principal de la página (h1) y la barra con el enlace a esta parte de la página. Sirve para Definir la cabecera del documento.
  • <main>: Envuelve todo el contenido central y único del proyecto. Ayudando así a los motores de búsqueda a identificar cuál es la información más importante de la página, en este caso al estar basada en una página promocional de un juego contiene cosas como de qué trata, donde jugarlo, personajes (en este caso las máscaras) y un apatartado con su banda sonora.
  • <section>: Se emplea para agrupar bloques de contenido temático y hacer el código mas legible y más sencillo de entender. En mí proyecto, separa la introducción, el tráiler, la ruleta de máscaras y el reproductor de música.
  • <footer>: Situada al final del documento, contiene los scripts de JavaScript (main.js) y los créditos de desarrollo.

Multimedia e Interactividad

  • <iframe>: Es fundamental para mostrar el tráiler oficial del juego desde YouTube sin necesidad de alojar el video pesado en el servidor local.
  • <audio> y <source>: Etiquetas multimedia utilizadas para crear el reproductor de la banda sonora. Me permitió vincular archivos locales (.ogg) y sus controlarlos mediante JavaScript.
  • <button>: El elemento semantico e interactivo. Se usó en conjunto con el evento onclick para disparar las funciones de JavaScript que hacen girar la ruleta y controlan la musica.
  • <img>: Utilizada para insertar los iconos de control y las imágenes pixel art (máscaras, disco de vinilo y controles), empleando el atributo alt para accesibilidad.
  • <li> y <ul> Me ayudaron a crear pequeñas secciones donde quiero mostrar una lista de algunos atributos a hablar del juego como sus Caracteristicas o las plataformas donde se puede jugar

Proceso de Creación

Crear este pequeño proyecto para mostras mis habilidades con la estructura semántica de una pagina web fue un reto bastante divertido, primero elegí una temática para la página, en este caso me decante por uno de mis juegos favoritos Hotline Miami que tiene una vibra bastante genial para colocar en una página web, y pensé en realizarlo como una página promocional del juego, y asi mostrar los diferentes usos de las etiquetas aprendidas en clase cuyas funciones ya explique en el segmento de arriba, algunos sprites como los de los botones los hice a mano en la página pixilArt para que combinaran con la estetica del juego y el resultado final del proyecto resultó bastante agradaable para mí y siento que es un buen ejemplo de como se podría elaborar una página web usando una buena semántica.
